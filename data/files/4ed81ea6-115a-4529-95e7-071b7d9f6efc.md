# motion.dev 设计体系拆解与 UI 方案

> 来源：motion.dev（原 Framer Motion 官网）线上 CSS 静态分析，色值为原生 OKLCH 精确值，非目测取色。
> 风格定位：**Technical Editorial / 实验室纸感** —— 暖米纸底色 + 近黑墨绿文字 + 锐利 1px 描边 + 单一高饱和柠檬黄强调。

---

## 一、配色体系

### 1.1 中性色（纸与墨）

所有中性色都带轻微色相（底色偏暖黄 hue 96、墨色偏冷绿 hue 148），**绝不使用纯灰**，这是"纸感"成立的关键。

| 令牌 | OKLCH | HEX | 用途 |
|---|---|---|---|
| `--paper` | `oklch(0.94 0.008 96)` | `#edebe5` | 页面底色、浅色容器 |
| `--ink` | `oklch(0.145 0.01 148)` | `#080b08` | 主文字、主按钮底色、页脚底色 |
| `--ink-raised` | `oklch(0.18 0.012 148)` | `#0e130f` | 深色容器、hover 加深 |
| `--line` | `oklch(0.31 0.012 148)` | `#2c322d` | 边框、分隔线（全站核心语汇） |
| `--muted` | `oklch(0.69 0.012 148)` | `#979d97` | 次级文字、标签、编号 |

### 1.2 强调色（水果调色板）

| 令牌 | OKLCH | HEX | 语义 |
|---|---|---|---|
| `--accent` (yellow) | `oklch(0.88 0.18 96)` | `#fbd509` | **唯一全局主强调**：导航底、CTA、高亮 |
| `--success` (rind) | `oklch(0.76 0.15 155)` | `#52cd86` | 成功、增长、正向指标 |
| `--danger` (watermelon) | `oklch(0.67 0.22 26.43)` | `#ff4945` | 错误、警告、危险操作 |
| `--info` (blueberry) | `oklch(0.68 0.18 255)` | `#3e98ff` | 链接、信息提示 |
| 装饰 (dragonfruit) | `oklch(0.72 0.2 345)` | `#f767c1` | 低频点缀、分类标记 |
| 装饰 (blackcurrant) | `oklch(0.64 0.18 302)` | `#a26ce5` | 低频点缀、Pro/付费标记 |

**配色四原则**：

1. **单强调原则** —— 柠檬黄承担 90% 的强调职责，彩色水果色只做低频点缀，避免视觉噪音。
2. **OKLCH 原生** —— 全部颜色以 OKLCH 定义，透明度混合用 `color-mix(in oklch, …)`，感知均匀。
3. **暖纸冷墨** —— 底色调暖、文字调冷，形成冷暖微对比。
4. **墨底反色块** —— 页脚与大标题区直接翻转为墨底纸字 + 黄色巨字，构成页面首尾视觉锚点。

## 二、图标配色规范

motion.dev 的图标策略是**极度克制**的，图标永远是配角：

### 2.1 默认规则

| 场景 | 图标处理 |
|---|---|
| 导航/工具栏图标 | **单色线条图标**，`stroke: var(--ink)`，1.5px 线宽，不填充 |
| 功能卡片图标 | 纯色圆点（10px）或单色线条图标，颜色取语义色（见下） |
| hover 态 | 线条色由 `--ink` 变为 `--accent`（黄）下的墨色，或容器加 1px `--line` 边框 |
| 交互按钮内图标 | 跟随文字色：主按钮 = 纸色，强调按钮 = 墨色 |

### 2.2 语义色映射（用于图标/状态点/徽标）

| 图标语义 | 颜色 | 示例 |
|---|---|---|
| 核心/品牌/中性功能 | `--ink` `#080b08` | 菜单、箭头、关闭 |
| 主强调/新功能 | `--accent` `#fbd509` | Star、Rocket、新功能角标 |
| 成功/在线/增长 | `--success` `#52cd86` | Check、状态点、增长箭头 |
| 错误/下线/危险 | `--danger` `#ff4945` | X、警告、删除 |
| 信息/链接/外部跳转 | `--info` `#3e98ff` | Info、外链箭头 |
| 付费/高级功能 | `--blackcurrant` `#a26ce5` | Pro 徽标、锁 |

### 2.3 禁忌

- ❌ 不使用多色/渐变填充图标（彩色 logo 场景除外）
- ❌ 图标不加阴影、不加圆角底板（需要底板时用 1px `--line` 描边的矩形/圆点）
- ❌ 同一视图内出现 3 种以上彩色图标

## 三、字体系统

| 层级 | 字体 | 字号 | 备注 |
|---|---|---|---|
| Hero 巨字 | TASA Orbiter | `clamp(110px, 18vw, 248px)` | 字重 700，字距 -0.03em |
| 章节标题 | TASA Orbiter | `clamp(24px, 5.4vw, 48px)` | 字重 700 |
| 小节标题 | TASA Orbiter | `clamp(19px, 1.7vw, 23px)` | 字重 600 |
| 正文 | TASA Orbiter | `clamp(19px, 1.7vw, 23px)` | 行高 1.55 |
| Micro 标签 | Geist Mono | 11–12px | **全大写 + 0.08em 字距** |
| 编号/代码 | Geist Mono | 12–13px | 01、02… 编号、版本号 |

开源替代方案：TASA Orbiter → **Inter** / General Sans；Geist Mono → **JetBrains Mono** / Geist Mono（开源版）。

## 四、布局规范

### 4.1 栅格

```
┌────────────────────────────────────────────────┐
│  gutter      max-width: 1440px        gutter   │
│ ◄──────► ┌──────────────────────────┐ ◄──────► │
│          │       内容区（居中）       │          │
│  clamp(20px, 5vw, 76px)             │          │
│          └──────────────────────────┘          │
└────────────────────────────────────────────────┘
```

- **最大宽度**：1440px，内容居中
- **页边距**：`clamp(20px, 5vw, 76px)` 响应式
- **网格间隙**：`clamp(16px, …)` 随视口收窄
- **内容区垂直节奏**：`clamp(44px, 6vw, 84px)`

### 4.2 布局语法

| 规则 | 说明 |
|---|---|
| 分隔 | 区块之间用 **1px 通栏实线**（`--line`）分隔，不用留白+阴影 |
| 卡片成组 | 多卡片用**负 margin 叠加 1px 边框**，形成共享描边的表格化网格 |
| 圆角 | **全站 0**（锐利矩形），仅圆点/头像用 `border-radius: 50%` |
| 阴影 | **无阴影**；层级用色块表达（如 `color-mix(in oklch, var(--accent) 22%, var(--paper))`） |
| 焦点态 | 输入框 focus = 墨色边框 + `2px 2px 0 var(--accent)` 黄色硬阴影 |

## 五、页面结构拆解（自上而下）

### 5.1 顶部导航 —— 标志性柠檬黄

```
██████████████████████████████████████████████████   ← 黄底 (--accent)
█ Motion /Docs /Examples /UI ...        [GET KIT] █   ← 墨色文字+等宽小CTA
██████████████████████████████████████████████████   ← 1px 墨色下边框
```

- 柠檬黄实底 + `1px solid var(--line)` 下边框，sticky 置顶
- Logo 左置；链接中等大小（14px）；右侧 CTA 为墨底纸字的等宽字小按钮

### 5.2 Hero 区

- Micro 标签行（等宽大写）→ 巨字标题（可达 248px，关键词用黄色高亮块包裹）→ 一段 lede 文案（max-width 640px）→ 元信息行
- 视觉重心靠左，右侧留白或放演示

### 5.3 特性网格

- 4–6 个特性卡：色点（10px 圆点，语义色）+ 标题 + 描述
- 共享 1px 描边的网格排布，无内阴影

### 5.4 编号列表（01–08）

```
01 │ Independent transforms │ 动画 x/y/rotate/scale…   │ TAG
02 │ Scroll animation       │ 硬件加速滚动动画…        │ TAG
───┴────────────────────────┴─────────────────────────┴──────
```

- 表格式行：等宽编号 + 标题 + 描述 + 右侧标签，行间 1px 分隔线
- 移动端折叠为两列（编号一行，标题描述一行）

### 5.5 示例/文档区

- 卡片网格（封面图 + 标题），1px 描边矩形
- 运行时切换用 pill 标签组（React / JavaScript / Vue）

### 5.6 页脚 —— 墨底反色锚点

```
██████████████████████████████████████████████████   ← 墨底 (--ink)
█            Paper & Ink.（黄色巨字）               █
█──────────────────────────────────────────────────█
█  方案    参考    字体替代    备注（四列链接）      █
██████████████████████████████████████████████████
```

- `--ink` 底 + 纸色文字 + **黄色巨字**（clamp 44–128px）
- 链接四列排布，分隔线为 `color-mix(in oklch, var(--paper) 22%, transparent)`

## 六、组件规范速查

| 组件 | 规格 |
|---|---|
| 主按钮 | 墨底纸字，等宽字体 13px，padding `12px 22px`，矩形 |
| 强调按钮 | 黄底墨字 + 1px 墨边框 |
| 幽灵按钮 | 透明底 + 1px `--line` 边框，hover 墨色 6% 混合 |
| 危险按钮 | 西瓜红底纸字 |
| 标签 pill | 等宽 11px，`padding 4px 10px`，1px 边框；彩色 pill 用语义色实底 |
| 输入框 | 纸底 + 1px `--line` 边框；focus = 墨边框 + 2×2px 黄色硬阴影 |
| 状态点 | 10px 圆形，语义色实心 |
| 代码块 | 墨底 + 纸色文字，语法高亮用黄/绿/蓝 |
